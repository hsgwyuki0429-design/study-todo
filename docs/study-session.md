# 学習の計測・途中再開・誤操作の取り消し

## 通常の例題

1. 「学習を開始」またはホームの例題行を押すと解答時間の計測を開始する。
2. 解き終えたら、計測中の例題行をもう一度押すか「解答終了・採点を始める」を押す。
3. ここからは採点・答え合わせ・解説確認・暗記の時間として計測する。
4. 採点・暗記が終わってから結果を選ぶ。結果を保存すると次の未完了例題を自動開始する。
5. 解答中も採点・暗記中も「一時停止」「再開」を使える。停止時間は計測しない。

「終了」はその日の学習実績を自動生成する操作ではない。
解答中／採点中のどちらでも、時間と段階を下書きとしてIndexedDBへ保存して止める。
次に「学習を開始」を押すと同じ例題・段階から続ける。数時間後、再読込後、翌日も対象。
例題を選び直す場合も、それまでの未確定時間は下書きに保持する。

途中状態は従来のsessionと同じくそのブラウザのIndexedDBに保存する。
別端末への下書き引き継ぎは追加していない。確定済み記録は従来どおりクラウド同期する。

## 今日の学習時間

ホーム左上と終了後の表示は、その学習日の累計を表示する。
学習日は03:00 JSTに切り替わる。たとえば9月14日の学習日は、
9月14日03:00から9月15日02:59:59までで、深夜0時を越えた分も9月14日分になる。
確定済みの学習時間、未確定の解答・採点時間、学習中に問題を選んでいない時間を含む。
「終了」してから再度開始するまでの時間と一時停止時間は含まない。
新しい計測では03:00 JSTの境界で実測時間を配分するため、境界をまたいで記録を確定しても
03:00より前に測った時間まで新しい学習日に加算しない。

旧記録は従来の合計時間をそのまま利用する。古い記録の解答／採点内訳は推測しない。

## 誤タップを戻す

- 結果を入れる前：「この取り組みを取り消す」でその例題の未確定時間を消し、未着手へ戻す。
- 結果を入れた後：ホームの「やったこと」から「未着手に戻す」を押す。
- スケジュール：日付→実施した問題→詳細の「未着手に戻す」を押す。

確認画面で対象を確かめてから取り消す。その回の結果・計測時間だけを削除し、
対応する例題の予定を未完了へ戻す。他の回の記録や、次に解いている例題は消さない。
予定日は変更しない。過去の予定を今日へ移す場合は既存の繰り越し操作を使う。
削除通知も保存するので、オフラインで取り消しても復帰後にクラウドへ反映される。

## 保存と互換性

新しい通常計測は`solveSeconds`と`reviewSeconds`（採点＋暗記）を保存し、
従来の`durationSeconds`にも合計を残す。日付をまたいだ実測の配分は`studySecondsByDate`に保持する。
旧バージョンから残った途中時間は`unclassifiedSeconds`として保持し、架空の内訳を付けない。
MCPの履歴取得・同期・バックアップでも新しい任意フィールドを保持する。
訂正後の合計と整合しない古い内訳はnormalize時に落とす。

結果・消費済み下書き・記録outboxは同一IndexedDB transactionで保存する。
同時保存ではsession／例題／予定項目／段階が一致する下書きだけを消費する。
取り消しも記録削除・予定の未完了化・plan metadata・削除outboxを同一transactionで更新する。

既存の03:00 JST日次Routineは変更しない。通常終了ではClaudeを起動せず、
すでにdeferredの日次イベントがある場合だけ、従来の終了通知で再開する。
MCPの権限・validation・revision・atomic applyも変更しない。

## 確認手順

スマホで例題を開始し、少し待って採点へ進み、一時停止・再開して結果を保存する。
次の例題が自動開始され、スケジュールの記録詳細で解答／採点・暗記の内訳が見えることを確認する。
別の例題では採点途中で終了し、アプリを開き直して同じ段階から再開することを確認する。
最後にホームとスケジュールの両方で誤記録を取り消し、時間と予定が戻ることを確認する。

配布時はPWAとWorkerを同じ版へ更新する。追加JSと03:00境界の更新はService Worker `aochart-v14`に含めた。
SecretやClaude Routineのプロンプト変更は不要。
