# 青チャート学習管理アプリ

青チャートの学習を記録・管理するスマートフォン向け PWA。勉強中にノートの隣にスマホを開いておく「伴走アプリ」として使う。

## 使い方

ビルド不要。静的ファイルをそのまま配信すれば動く。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ をスマホのブラウザで開き、ホーム画面に追加
```

初回起動時に `data/questions.json`（青チャート数学I+A の問題マスタ 591問）が投入される（`src/seed.js`）。

## ホーム画面

上半分＝タイマー（固定）、下半分＝可変エリア。学習中に画面遷移は行わない。

**タイマーは二段表示**。左上に小さく「学習時間」（セッション全体。問題を切り替えても止まらない）、中央に大きく現在の問題の累積時間。

下半分は4状態を切り替わる。

1. **待機** — 今日の累計時間 ＋「学習を開始」。「やること / やったこと」の切り替え
2. **タスクリスト** — 例題を1問ずつ展開。チャレンジは1行として混在
3. **記録入力** — 5択を1タップで記録
4. **チャレンジ** — 制限時間付き。全体タイマーと問題ごとの累積ストップウォッチが並行して動く

記録した問題は**リストから消える**。記録後に次の問題が自動で始まることはなく、**やりたい問題を自分でタップしたときに計測が始まる**（順番通りに進むことを強制しない）。

## チャレンジ

問題をタップして切り替えても**評価は聞かれない**。元の問題は一時停止するだけで、戻れば続きから加算される。何度行き来してもよい。

問題リストの一番下にある「終了」を押すと、**そこで初めて全問の評価入力**に移る。対象の各問題について5択を順に入力し、入力が終わった時点で結果（制限時間内に終えられたか・各問のラップタイム・各問の評価）が保存される。

## 記録タブ

- **目次ビュー** — 章 → 単元 → 例題とたどり、1問の過去の履歴（日付・評価・所要時間）を見る。評価が時系列に並ぶので推移が読み取れる（✕ → △ → ◯）
- **履歴ビュー** — 新しい順の時系列表示。章・単元・評価でフィルタ

章ごとの進捗パーセンテージは表示しない。

## スケジュールタブ

上半分がカレンダー（月 / 週 / 年、矢印で前後に移動）、下半分がその期間の進捗バー。

**カレンダーのマス**は日ごとの達成率を表す。表示方式は設定で選ぶ。

- **リング型** — 日付を囲む円の枠線が進捗バーになり、達成率で色が変わる（高い=成功色 / 中間=警告色 / 低い=危険色）。未来の日付は細い枠線のみ
- **塗り型** — 背景の塗りの濃さで達成率を表す。ベースカラーは「ランダム / 月ごと / 週ごとグラデーション」から選べる

**進捗バー**は、その期間に終わらせるべき範囲を1本のバーにしたもの。目盛り1つが1問に対応し、その問題の評価で色が変わる（◯=成功色、解/記=アクセント色、△=警告色、✕=危険色、未着手=枠のみ）。チャレンジも同じくバーで表示する。

日付をタップするとその日のTODOが出る。過去の日付なら、終わったか・どの評価だったかが分かる。

## タイマーの設計

経過時間は `setInterval` の加算ではなく、開始時刻（`Date.now()`）との差分から算出する。バックグラウンド遷移・画面スリープ・アプリの再起動をまたいでも正しい経過時間を保つ。

セッション状態は `SessionState` として IndexedDB に永続化され、アプリを閉じても計測中の状態が復元される。

## 評価の5択

| 値 | 記号 | ラベル |
|---|---|---|
| `perfect` | ◯ | 完璧にできた |
| `better_solution` | 解 | 正解だが、もっと簡単な解法があった |
| `weak_writing` | 記 | 正解だが、記述が甘い |
| `calc_error` | △ | 計算ミス |
| `wrong_approach` | ✕ | 方針が違った |

メモ欄・原因タグは設けない（原因は5択に内包される）。

## クラウド同期と MCP 連携（任意）

学習データを Cloudflare（Worker + KV）へ預けると、Claude などの MCP 対応AIから
学習状況を読み取り、今日のTODOや目標を変更できる。変更は次に同期したときPWAへ反映される。

```
study-todo（PWA・IndexedDB）
      ↓↑
Cloudflare Worker + KV  →  MCP Server  →  Claude などのAI
```

**この連携は追加機能**であり、設定しなければ今までどおりブラウザの中だけで動く。
サーバーが落ちていても、オフラインでも、学習の記録・タイマー・カレンダーはすべて使える。
オフライン中の記録は端末に貯まり、オンラインに戻ったときにまとめて送られる（何度送っても
`id` で重複しない）。

**AIは学習実績を作れない。** 公開しているのは「読む」ツールと「これからの予定・目標を
変える」ツールだけで、学習記録とチャレンジ結果を作れるのはPWA本体だけ。

| 種類 | 同期 |
|---|---|
| 学習記録・チャレンジ結果 | する（追加専用イベント。`id` で重複排除し、合計はサーバーで数え直す） |
| その日の予定（TaskPlan） | する（日付ごとに `revision` で競合を解く） |
| 目標 | する |
| 問題マスタ | する（指紋が変わったときだけ送る） |
| 計測中のタイマー・表示設定 | しない（端末ごとのもの） |
| 管理キー・端末キー・接続トークン | しない（端末の中だけ。バックアップJSONにも入らない） |

設定手順（Cloudflare の準備からClaudeへの登録まで）とツールの一覧は
**[docs/mcp.md](docs/mcp.md)** にある。

主なツール:
`getAppInfo` / `listQuestions` / `searchQuestions` / `getQuestion` / `getStudyHistory` /
`getRecentMistakes` / `getStudyStats` / `getRecentChallengeResult` / `getChallengeResults` /
`getTodayTasks` / `getTasksInRange` / `getGoals` / `getRecentAiChanges` /
`updateTodayTasks` / `updateTasksForDate` / `addGoal` / `updateGoal`

サーバー側のテストは `npm test`（Node標準のテストのみ。PWA本体は引き続きビルド不要）。

## 日付の扱い

「今日」は日本時間（UTC+9）で判断する（`src/datetime.js`）。ISO文字列の先頭10文字をそのまま
使うと、深夜〜朝に前日として扱われてしまうため、日付の判定はすべてこのモジュールを通す。
MCPのツールでは `timezoneOffsetMinutes` で別の時間帯も指定できる（既定は540）。

## 問題マスタのインポート

設定タブの「問題をインポート」から `Question[]` の JSON を貼り付けて投入する。

```json
[{ "subject": "数学I+A", "chapter": "数列", "section": "漸化式", "type": "例題", "number": 90 }]
```

`id` を省略すると `subject-type-number` から生成される。設定タブからは全データの JSON 書き出しもできる。
書き出したJSONに、管理キー・端末キー・接続トークンなどの秘密は含まれない。

## 問題マスタ

`data/questions.json` は、数研出版「チャート式 基礎からの数学I+A（青チャート）」の
目次・章トビラの例題一覧・EXERCISES ページから起こした**管理用メタデータ**である。
問題文と解答は含まない。

| | 数学I | 数学A | 計 |
|---|---|---|---|
| 例題（基本・重要・演習） | 194 | 156 | 350 |
| EXERCISES | 134 | 107 | 241 |
| 計 | 328 | 263 | 591 |

1問 = 「1回解いて1回評価する単位」。例題の (1)(2)(3) は同じ1問として扱う。

例題（350問）の種類・タイトル・難易度は、誌面の拡大読み取りに加えて、
数研出版が配布している例題一覧（改訂版）と突き合わせて確認済み。
EXERCISES（241問）の難易度は読み取りが未確認のため `needsReview: true` を付けてある
（番号・掲載ページ・所属する節は確認済み）。

元になる表は `tools/source/math1.mjs` と `tools/source/matha.mjs` にあり、
直したら次を実行して `data/questions.json` を作り直す（整合性チェックつき）。

```sh
npm run build:questions
```
