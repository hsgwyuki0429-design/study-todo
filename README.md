# 青チャート学習管理アプリ

青チャートの学習を記録・管理するスマートフォン向け PWA。勉強中にノートの隣にスマホを開いておく「伴走アプリ」として使う。

## 使い方

ビルド不要。静的ファイルをそのまま配信すれば動く。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ をスマホのブラウザで開き、ホーム画面に追加
```

初回起動時にサンプルの問題マスタ・タスク・目標が投入される（`src/seed.js`）。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨格（ホーム / 記録 / スケジュールの3タブ） |
| `styles.css` | フラットな配色。ダークモード対応、タップ領域44px |
| `src/app.js` | 状態機械・タイマー・描画 |
| `src/api.js` | データアクセス層（MCPツールと1:1対応） |
| `src/idb.js` | IndexedDB ラッパー（保存先の差し替え点） |
| `src/seed.js` | 初期データ |
| `sw.js` | アプリシェルのキャッシュ（オフライン起動） |

## ホーム画面の4状態

上半分＝タイマー（固定）、下半分＝可変エリア。学習中に画面遷移は行わない。

1. **待機** — 今日の累計時間 ＋「学習を開始」。下半分は「やること / やったこと」の切り替え
2. **タスクリスト** — AIが並べた優先順に例題を1問ずつ展開。チャレンジは1行として混在
3. **記録入力** — 5択を1タップで記録。保存後は自動でタスクリストへ戻り、次の問題が計測開始
4. **チャレンジ** — 制限時間付き。全体タイマーと問題ごとの累積ストップウォッチが同時並行で動く

行をタップすると計測対象が切り替わり、元の問題は一時停止して累積時間を保持する。戻ると続きから加算される。計測中の行をもう一度タップすると記録入力に移る。

## タイマーの設計

経過時間は `setInterval` の加算ではなく、開始時刻（`Date.now()`）との差分から算出する。バックグラウンド遷移・画面スリープ・アプリの再起動をまたいでも正しい経過時間を保つ。

セッション状態は `SessionState` として IndexedDB に永続化され、アプリを閉じても計測中の状態が復元される。

## 評価の5択

| 値 | 記号 | ラベル |
|---|---|---|
| `perfect` | ◯ | 完璧にできた |
| `better_solution` | 解 | 正解だが、もっと簡単な解法があった |
| `weak_writing` | 記 | 正解だが、記述が甘い |
| `calc_error` | △ | 計算ミス |
| `wrong_approach` | ✕ | 方針が違った |

メモ欄・原因タグは設けない（原因は5択に内包される）。

## MCP連携

`src/api.js` が MCP サーバー側から呼ばれる想定の関数を提供する。

`getAppInfo` / `listQuestions` / `searchQuestions` / `getQuestion` / `getStudyHistory` / `getRecentMistakes` / `getStudyStats` / `getRecentChallengeResult` / `getTodayTasks` / `updateTodayTasks` / `getGoals` / `addGoal` / `updateGoal`

現状の保存先はブラウザの IndexedDB のみ。サーバー同期に移行する際は `src/idb.js` を差し替え、`src/api.js` のシグネチャを維持すればよい。

## 問題マスタのインポート

記録タブの「問題をインポート」から `Question[]` の JSON を貼り付けて投入する。

```json
[{ "subject": "数学I+A", "chapter": "数列", "section": "漸化式", "type": "例題", "number": 90 }]
```

`id` を省略すると `subject-type-number` から生成される。
